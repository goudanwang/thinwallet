# Multi-Device Android Evaluation

This is a future evaluation plan, not a completed result. Test at least three
physical ARM64 devices spanning memory and CPU tiers. For each device record
SoC, Android/API level, RAM, kernel, ABI, thermal/battery state, app build hash,
network profile, five W1-W4 E3/E4 repetitions, RSS/PSS, wall/CPU time, energy,
temporary storage, proof hash, unchanged-verifier result, timeout behavior, and
token terminal state. Include cold/warm runs and foreground/background limits.

Do not begin until an authorized device is available and the desktop artifact
hashes have been frozen.
