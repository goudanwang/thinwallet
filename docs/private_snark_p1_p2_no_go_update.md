## Updated No-Go

P2 alone does not achieve phone-light private SNARK proving when phone online
cost remains O(number of multiplications).

P1 alone does not achieve phone-light private SNARK proving when correction is
O(N) or O(N log N).

The P2 model assumes trusted preprocessing. The model is no longer pure
single-server online assistance unless preprocessing is generated by the phone,
issuer, dealer, or prior offline phase.

The next direction should not be more of the same P1/P2 toy pipeline. It should
either move toward P3 correlation-assisted preprocessing with a credible setup
model, or redesign the proof system so nonlinear work is not exposed as phone
online O(m).
