# Real Credential Workload Plan

The next workload phase should replace the synthetic Boolean-multiplication
relation with the measured credential components while preserving the frozen
FS6 prover and unchanged verifier as controls.

Record relation size, private nonlinear constraints, witness layout, all MSM
shapes, request-dependent state, credential selection, issuer validity,
credential-key binding, disclosure, freshness, and revocation. Run component
ablations before a combined presentation. Report peak RSS, phone-visible work,
I/O, temporary storage, proof size, latency, transcript/proof identity where
applicable, and included/excluded security components.

This plan does not claim that credential semantics, server-only continuation,
secret sharing, or A2DP delegation are implemented.
