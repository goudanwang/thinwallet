# P1/P2 Minimal Hybrid Experiment

Original goal:

```text
single-server assisted private SNARK proving
```

This experiment asks whether masked linear offload plus client-assisted
multiplication can reduce phone online work enough to be meaningful.

## Implemented Toy Pieces

P1 masked linear offload:

- phone masks private vector `w` as `w + r`;
- server computes public linear transform on the masked vector;
- phone subtracts `M*r`.

P2 client-assisted multiplication:

- additive sharing over the BN254 scalar field;
- Beaver-style multiplication with trusted preprocessing triples;
- semi-honest toy setting only.

Hybrid toy R1CS:

```text
for j = 1..m:
    c_j = a_j * b_j

y = L * [a, b, c, public]
```

## Answers

Does P1 reduce phone cost, or merely shift computation?

P1 preserves privacy for the linear transform in the toy model, but phone
correction computes `M*r`. In this experiment it remains O(N) or O(N log N),
depending on the transform.

Does P2 make nonlinear witness computation private but still phone-linear?

Yes. P2 hides multiplicands from the semi-honest server, but phone online work
and communication are O(number of multiplications).

Does the hybrid approach plausibly beat local proving on phone?

Not in the current toy form. Both nonlinear multiplication assistance and
linear correction leave phone costs that scale with the private computation.

What preprocessing assumptions are required?

P2 assumes trusted Beaver triple preprocessing. The model is not pure
single-server online assistance unless preprocessing is generated by the phone,
issuer, dealer, or a prior offline phase.

Can the final output still be a standard SNARK proof?

Not demonstrated. This experiment only checks toy R1CS values and cost
boundaries; it does not integrate a Groth16 or Plonkish prover.
