# Phase V4 Mobile Network And Server Plan

Status: NOT STARTED. The current PBMO provider uses the WSL experimental transport profile.

The mobile phase must implement bounded request/response framing, backpressure, authenticated session/proof/basis binding, replay rejection, reconnect semantics, and token crash recovery. Measurements must separate phone masking, upload, server MSM, download, recovery, and batch integrity. A production claim requires malicious-server tests on the deployed transport.
